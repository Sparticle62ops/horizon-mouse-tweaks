# Mouse Tweaks for Horizon

A Rust port of MouseTweaks (BSD 3-Clause, (c) 2023 Ivan Molodetskikh,
https://github.com/YaLTeR/MouseTweaks) for Horizon native mods. 1:1
behavior: left-drag pickup, right-drag distribute, and wheel push/pull of
items between slots, with the original's config keys. Settings are driven
by the /mousetweaks command instead of the original's MouseTweaks.cfg.
